# 個人戦績

## 公開画面

- `/g/:groupCode/stats`: グループ内ランキング。標準は累計損益BB順。タブは累計損益、平均損益、直近3戦、TOP3回数、順位率、最大勝ち、最大負けの順
- `/g/:groupCode/stats/:groupPlayerId`: KPI、累計損益BB推移、開催別結果を表示する
- どちらも参加者へ公開し、主催者認証は要求しない
- グループトップに横幅いっぱいの「個人戦績を見る」導線を置く
- ランキング行は称号設定の有無・上位3人かどうかに関係なく、一覧内の最も高い行と同じ高さに揃える。名前直下に共通の称号スロットを確保し、称号なしは薄い破線枠の「—」プレースホルダーを表示して統計行の位置も揃える。内容や文字サイズに応じて全行が伸縮する

## 集計元

現在有効な確定結果である`game_results`だけを正とする。`games.status = 'finalized'`の開催に限定し、開催途中の`game_participants`は含めない。

訂正時は`game_results`が現在結果へ置換され、過去スナップショットは`game_result_revisions`へ保存される。戦績SQLは訂正履歴をJOINしないため、同じ開催を二重集計しない。

## 損益BB

開催ごとに保存された`big_blind_chips`をポーカー上の1BBとして計算する。開始スタックBBは入力値ではなく、初期チップとBBからの派生値である。

```text
score        = remaining_chips - settlement_rebuy_count × rebuy_chips
profit_chips = score - initial_chips
net_bb       = profit_chips ÷ big_blind_chips
```

確定結果画面、共有文、個人戦績はすべて同じ損益BBを使用する。`initial_chips`と`big_blind_chips`は開催作成時に正の整数として検証する。万一不正な確定済みデータが存在した場合は黙って除外せず、集計エラーとして検出する。

PostgreSQLでは途中の整数除算を避けるため`NUMERIC`へ変換してから計算する。画面表示は最大小数第2位とし、正数には`+`を付ける。

## 集計構成

```text
stats route loader
  → PlayerStatsService
    → PlayerStatsRepository
      → PostgreSQL
```

- ランキングの参加回数、優勝回数、累計、平均、最大勝ち、最大負け、直近3参加平均、TOP3回数、平均順位率はSQLで現在・前回の2集合に集約する。順位はserviceとブラウザが共通のdomain関数で計算する
- 個人詳細は確定結果を時系列で取得し、serviceから純粋関数を呼んでKPIと累積値を作る
- ランキングは確定済み開催への参加が1回以上あるメンバーだけを対象とし、参加0回の登録メンバーは表示しない
- Rechartsの`ResponsiveContainer`と`LineChart`で固定横幅を持たない累計損益BB推移を表示する

## ランキング指標

- 累計: 全確定結果の損益BB合計。高い順
- 平均: 全確定結果の平均損益BB。高い順
- 最大勝ち: 1開催の正の損益BB最大値。高い順。プラスがない場合は0
- 最大負け: 1開催の負の損益BB最小値。損失が大きい順。マイナスがない場合は0
- 最近: 本人が参加した直近3開催（3回未満は存在する分）の平均損益BB。高い順。上振れ・下振れ等の評価ラベルは付けない
- TOP3: 3位以内に入った開催数。多い順
- 平均順位率: 開催ごとの`順位 ÷ その開催の参加人数 × 100`を平均する。参加人数の差を補正し、低い順

ランキングカードは選択中の指標だけを表示し、別指標の補助表示は行わない。指標切り替えはスマートフォンで横スクロールできるタブとする。

## 前回比

- 現在は全確定開催、前回は開催日時が最新の確定済み開催1件を除いた集合から計算する。最新の順序は`played_at DESC, finalized_at DESC, id DESC`とし、最後に確定操作した開催とは区別する
- 直近3戦はそれぞれの集合内で本人の直近3参加を選び直す。欠席者の成績は変わらなくても、他者との順位差は表示する
- 指標と既存の補助指標がすべて同値なら同順位（1、1、3位）とする。表示名・IDは同順位内の表示順だけに使う
- 順位の下に上昇`↑2`は緑、下降`↓1`は淡い赤の小型バッジ（太字・薄い同系色背景）で表示する。色は全指標で順位の移動方向を表す。変動なし`—`は中立色・背景なしで控えめに表示する。矢印と読み上げラベルも残し、前回順位なしは非表示とする。`NEW`や架空の順位を作らない
- 7指標の前回順位を最初のloaderでまとめて返すため、タブ切替時は追加通信しない
- 過去の訂正や確定取り消し時は、現在有効な確定結果から現在・前回とも再計算する。当時の表示を固定保存する機能ではなく、DBテーブル・カラムは追加しない

## 今回の範囲

- ランキング（上記7指標の切り替え）
- 個人詳細の主要指標は参加回数、優勝回数、TOP3率、プラス率とし、率には該当回数と全参加回数を併記する
- TOP3率は3位以内の開催数を全参加開催数で割り、プラス率は損益BBが0より大きい開催数を全参加開催数で割る。0BBはプラスへ含めない
- 累計・平均損益BB、最大勝ち・最大負けBB
- 累計損益BB推移と開催情報Tooltip
- 新しい順の開催別結果と確定結果への導線

順位推移グラフ、年別フィルター、累計リバイ統計・リバイ率、シーズン集計、連勝・連続入賞、自動ハイライトは次の拡張候補とする。
